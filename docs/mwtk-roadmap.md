# MWTKgram — список будущих фич

Статус: **записано, не делаем** до команды doxmev.

## 1. Летающий текст песни (ПК, потом Android)
Утверждён по демо (lyrics_demo v2).
- Текст с таймингами: свой `.lrc` рядом с треком → теги трека → поиск в базе LRCLIB по исполнителю и названию, найденное кэшируется.
- Если строчки размечены только по времени, оно делится между словами по их длине. Расширенный LRC с таймингом слов используется как есть.
- Слова загораются по буквам в такт.
- Расположение:
  - **По словам** (по умолчанию): 1–3 ряда, разный размер, лёгкий наклон, каждое слово вылетает со своей стороны, строчки появляются в разных местах экрана.
  - **Лесенка.**
  - **Строкой.**
- Как пропадает (по очереди, слово за словом):
  - **Искры** (можно выключить);
  - **Растворение**;
  - **Улетает вверх.**
- Стиль: Неон, 3D, Пиксели. Ползунки «Движение слов» и «Размер».
- Ползунок «Сдвиг» для треков с вступлением, которого нет в тексте. Редактор синхронизации для треков, которых нет в базе: вставить текст, на каждой строчке нажимать пробел, результат сохраняется в `.lrc`.
- Анимация работает только во время воспроизведения, чтобы процессор не грузился.

## 2. Режим «Спрятать чаты» для текста песни (ПК и Android)
- Правый клик (или долгое нажатие) по песне → пункт **«Спрятать чаты»** с переключателем.
- Пока он включён и играет трек, чаты и интерфейс плавно скрываются, а летающий текст занимает **весь экран** поверх фона (надписи или 3D-сцена).
- Выход: тот же пункт меню, клавиша Esc / кнопка «Назад», а также автоматически, когда трек закончился.

## 3. Прозрачность всего приложения (Android)
Два независимых ползунка:
1. **Список чатов** — как сейчас на ПК.
2. **Всё приложение**: папки, шапка, переписка, меню, настройки, панели. Фон (надписи или 3D) просвечивает сквозь весь интерфейс.

При любом значении текст должен оставаться читаемым: у текста лёгкая тень или подложка, а не сплошная прозрачность.

## 4. Летающие чаты на Android
- Включаются отдельным жестом. Варианты: встряхивание с удержанием, тройной тап по шапке или долгое нажатие на заголовок. Встряхивание уже занято «эффекты вкл/выкл», поэтому жест нужно выбрать.
- Весь интерфейс, кроме фона, расплывается. **Все чаты превращаются в кружки-аватарки** и летают по экрану. В отличие от ПК, обычный список не остаётся: на телефоне для этого нет места. Кнопки (поиск, новое сообщение, настройки) тоже становятся летающими кружками.
- Кружки **реагируют на наклон и поворот телефона**: «скатываются» по гироскопу, отталкиваются от краёв и друг от друга. Их можно бросать пальцем, как F8 на ПК.
- Тап по кружку открывает чат. Выход из режима тем же жестом или кнопкой «Назад».
- Пока режим открыт, работает физика. Режим «Беречь батарею» её отключает.
