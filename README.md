# RASPIgram

Неофициальный клиент Telegram для Windows на основе Telegram Desktop.

- зелёная тема и летающий по экрану текст;
- текст песен на экране;
- удалённые сообщения;
- режим призрака: без «в сети», «печатает» и отметок о прочтении;
- чеклисты;
- AI-редактор постов на своём API-ключе (OpenAI, Claude, Gemini и другие);
- погода каждый день напоминанием в «Избранное».

Скачать: раздел Releases, файл `RASPIgram-Setup.exe`.
